# 굿즈함

사고 싶은 굿즈와 이미 데려온 굿즈를 사진으로 모아 두는 **덕질 기록 앱**이에요.
앱스토어 설치 없이 폰 브라우저에서 바로 쓰고, 홈 화면에 추가하면 앱처럼 열려요.

👉 **바로 쓰기: https://kdh3207.github.io/goodsham/**

## 이런 걸 할 수 있어요

- **굿즈 저장**: 사진(여러 장), 이름, 발견한 날·장소·가게, 내가 본 가격·온라인 가격, 품절·한정판, 애정도, 메모
- **굿즈함 목록**: 카테고리별로 모아 보기, 정렬(가격·날짜·애정도), 구매 완료만/미완료만 보기, 사고 싶은 굿즈 합계
- **상세 화면**: 사진을 포토카드에 담아 보여 주고, 구매 완료하면 카드 테두리가 금색으로 바뀌어요
- **덕질 기록(홈)**: 이번 달 덕질비, 월 예산 막대, 카테고리별·월별 지출, 최근 구매
- **여러 개 한 번에**: 꾹 눌러 선택한 뒤 카테고리 넣기 · 복사 · 삭제
- **꾸미기**: 테마 색, 배경 사진, 움직이는 효과
- **친구와 공유**: 고른 굿즈를 파일로 만들어 보내고, 친구가 보낸 파일을 열어 내 굿즈함에 담기
- **백업**: 백업 파일로 내보내기 · 불러오기

## 폰에 설치하기

- **아이폰**: Safari로 위 주소 열기 → 아래 공유 버튼 → **홈 화면에 추가**
- **안드로이드**: Chrome으로 위 주소 열기 → 메뉴(⋮) → **홈 화면에 추가** 또는 **앱 설치**

## 내 데이터는 어디에 저장되나요?

굿즈 정보와 사진은 **내 폰 안(브라우저 저장소)에만** 저장되고, 어떤 서버로도 보내지 않아요.
그래서 로그인이 필요 없고, 다른 사람은 내 굿즈함을 볼 수 없어요.

다만 브라우저 데이터를 지우거나 앱을 삭제하면 사라질 수 있으니,
가끔 **메뉴(☰) → 백업 파일로 내보내기**로 백업해 두세요.

## 보안

- 받은 백업·공유 파일은 저장하기 전에 모든 내용을 검사해요 (가짜 링크·숨긴 코드·비정상 값 차단).
